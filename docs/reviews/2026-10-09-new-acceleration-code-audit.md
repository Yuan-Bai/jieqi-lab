## 逐项判断

- **完整机会概率表复用**（[azero.py:1336](../../azero.py#L1336)、
  [原生计数防护](../../native/jieqi_rules.pyx#L14)）：
  缓存只接受标准不可变整数计数，排除 bool、浮点、NumPy 标量及子类，避免数值相等但计算舍入不同的键碰撞。
  原生防护使用 `PyLong_CheckExact`，不把任意大整数转换为 C 整数。结果为不可变 tuple，当前调用点只读取；
  LRU 上限 4096，淘汰后重新计算。枚举函数/棋种顺序被替换或没有原生防护时走原实现。
  真实世界揭示采样、节点统计、网络输出均不进入该缓存，采样 RNG 调用位置未改变。
- **中间信息态快照削减**（[直接信息集键](../../ismcts.py#L223)、
  [共享字段格式](../../ismcts.py#L297)、[叶快照](../../azero.py#L1834)）：
  直接键与旧快照键共用同一 15 字段格式，只投影当前行动者的观察槽，保留公开/私有观测链及长将/长捉字段。
  不访问真实世界暗池或另一观察者的私有槽。键立即冻结，待评估叶仍分配独立完整快照；
  根的零深度叶复用根快照，终局/无合法着的叶不额外分配。
  检查了延迟到合法着判定之后才复制的恢复约定；相应恢复、私有捕获和 pending 批所有权测试通过。
- **三个 Cython 原型**：编码只将已验证的小整数棋盘循环降为 C 整数，浮点表达式继续使用 Python 对象；
  PUCT 保留原 generator 求和、表达式顺序、严格大于比较及插入顺序平局选择；
  历史身份复用仅缓存标准不可变棋盘的材料签名和 bytes，持有强引用并复核身份，计数/轮次/字典顺序每次读取。
  原型具备不支持输入的回退、容量边界以及源码/函数/解释器/实际扩展路径校验。
  本轮显式加载现有三个匹配二进制，没有重新编译生产扩展；生产模块没有自动加载这些原型的入口。
- **阻塞等待**：每设备事件记录当前流，再阻塞同步，最后保留原 `.cpu()`。
  AST 替换要求唯一且无参数的原复制调用；上下文退出恢复两个方法。它只存在于隔离工具。
- **FP16/BF16/TF32**：作用域恢复原精度开关，网络输出先转回 FP32，再进入原 softmax/搜索。
  棋力入口核对吞吐门槛、来源和实际后端，并检查前向输出有限性。
  这些精度模式会改变网络/搜索结果，不能算作位级等价加速；本轮没有另跑精度棋力试验。
