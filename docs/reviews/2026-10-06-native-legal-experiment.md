# 合法着快路精确编译实验（2026-10-06）

结论：**快路微测稳定降低约 37%–40% 耗时，但 8-worker 整体收益小且波动明显，
不默认投入训练。** 两次独立六组配对平均分别省 1.82% / 1.11%，合计平均 1.46%，
单组范围为 -5.10% 至 +5.07%。保留实现、显式开关及复测工具，不将微测收益外推为整轮收益。

这是节点编译实验之后的独立候选，范围仅为没有长将/长捉禁着时的合法着快路。
当前默认仍保留 Python 合法着实现，攻击判定 Cython 与节点 Python 的选择不变。
未改变规则/搜索/数据版本、训练配置、模型或生产 replay。

## 实现边界

- 新增独立 `native/jieqi_legal.pyx` / `_jieqi_legal`，没有重建原有攻击判定二进制。
- 只替换 `GameState._iter_legal_moves_fast`；在该快路内部编译伪合法着枚举。
  公共 `iter_pseudo_moves`、长将/长捉 apply/undo 慢路和裁判逻辑保持原 Python 方法。
- 保留棋子扫描、射线、马腿/象眼、暗士/明士、过河兵、飞将及着法输出顺序。
  不缓存合法着、不跳过候选、不消耗随机数、不提前物化生成器。
- 棋盘与将位置在每次 yield 前恢复；提前结束/close 不遗留试走。攻击回调仍通过
  `self.is_square_attacked` 调用，包含回调抛异常时与原实现相同的部分更新行为，
  没有顺便改动原异常语义。
- 普通 Python 整数先按掩码取低位，再转换 C int，超大/负整数不会溢出；
  其他棋子数值类型继续调用原 Python 位运算助手。没有浮点重排或精度切换。
- 非标准棋盘/side、子类、被替换的伪合法方法/位运算助手/棋子常量使用 Python 回退。
  编译内部使用项目正常的预计算走法表；不承诺任意运行时破坏走法表的行为等价。
- 保留 `boundscheck=True`、`wraparound=True`；类型推断及注解推断关闭。
  棋盘仍是 Python list，不引入 C 棋盘、对象池或新的节点布局。

每个 GameState 类绑定自己的模块上下文，不用原生模块全局上下文；克隆模块、CLI 和
spawn 的指纹/上下文隔离均有测试。两个原始方法及三个位运算助手也留作基准与回退。

## 开关与来源记录

## 测量方法

工具：`tools/benchmark_native_legal.py`。只读取当前
`data/train_rules5_20261004/models/training_checkpoint.pt`，使用其中完整模型及配置。
不更新网络、不推进训练轮次、不写入样本或日志；输出独占创建，拒绝覆盖已有结果。

800/3200 模拟、leaf batch64、机会节点开启/k0、叶去重、虚拟损失、温度、根噪声、
策略裁剪、FP32/TF32 设置保持不变，节点仍为 Python，攻击判定仍为同一 Cython 二进制。

局面集沿用上阶段方法：三局真实模型 800 模拟自博弈（47/78/10 ply）抽取 18 根，
加 4 个捕获优先轨迹根、2 个受控残局，共 24 根，包含私有捕获和不同历史/材料。
重复固定根不是同等数量的独立局面，也不代表完整 1024 局的生产频率。

微测每组 24 根 x 128 次，六轮交替先后顺序；包含生成器、查询及完整合法性过滤。
8-worker 预热后每组 24 根 x 4 种子块 = 96 次搜索，其中 12 次 strong3200，其余 800；
strong 根随种子块轮换。六组配对交替顺序，不计进程启动及局面生成。
完整树检查另对 8 根 x 800/3200 = 16 组比较 pickle 图，不将保留树的耗时用于吞吐。
两局完整自博弈是单 worker 的样本一致性验收，不是平均对局提速估计。

## 验收与选择

新增测试覆盖所有棋子、颜色、明暗、90 个源格及阻挡组合、随机/超大/负整数棋盘、
NumPy 和整数子类、缺将/异常索引/棋盘类型、生成器提前结束/close/throw、攻击异常的
部分更新、子类/自定义回调回退、八局随机轨迹及三种禁着组合、apply/undo、状态/RNG
不变、CPU 完整搜索（机会节点关闭/全枚举/惰性和去重开关）、模块隔离、CLI/spawn 来源。
另检查真实外部预加载二进制及加载文件随后改变时的拒绝记录行为。

最终回归：默认配置全量 405 项通过，113.66s；显式启用合法着 Cython、节点仍为
Python 时全量 405 项通过，112.39s；强制攻击判定/合法着/节点后端均为 Python 的
相关 56 项通过，36.41s。本次未再跑完全 Python 的全量套件，也未跑节点 Cython
与合法着 Cython 联合启用的全量套件。相关源码 `py_compile`、`git diff --check`
及新增文件尾随空白检查通过。

这些有限对照没有观察到语义差异，但不是所有未来局面的数学证明；原方法和原生体
存在维护漂移风险，靠指纹与回归约束。小幅整体均值和波动尚不足以默认启用，保持
原训练命令有效、buffer 与检查点不变。继续实验可以显式开启，但本次不推荐为了
吞吐数字改模拟数、叶 batch、精度或采样方式。未跑完整 1024 局生产轮次或收敛实验。

## 复现

使用上阶段已安装到 `data/build_deps` 的 Cython 3.3.0 和本机 MSVC/SDK：

```powershell
python tools/build_legal.py
$env:JIEQI_LEGAL_BACKEND="cython"
$env:JIEQI_SEARCH_BACKEND="python"
python -m pytest -q test_native_legal.py
python tools/benchmark_native_legal.py --pairs 6 --blocks 4 --workers 8 --complete-games 2 --output data/pilots/perf_20261006/native_legal_new.json
Remove-Item Env:JIEQI_LEGAL_BACKEND
Remove-Item Env:JIEQI_SEARCH_BACKEND
```

输出必须使用既有目录中的新文件。测量时不要同时训练、测试或修改被测源码。
有限对照不是任意未来局面的数学等价证明；本实验没有证明学习收敛速度，也没有改变
训练所需数据、模拟预算或优化器。
