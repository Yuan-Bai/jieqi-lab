# 集中 GPU 推理原型实验

> 公开副本说明：个人绝对路径已改为相对路径或占位符；标注“未随源码分发”的实验材料仅作为历史记录，不能从本仓库下载。复现命令中的 `<PROJECT_ROOT>` 等占位符需替换为自己的路径。

日期：2026-10-06。

## 结论

**集中、不合批的工程路径通过了本轮验证；跨请求合批未通过数值等价门槛。
保留独立原型，不接入生产训练。**

- 原批次集中执行：逐请求位级检查通过；64 局吞吐对照样本也全部一致。
  不计启动，耗时缩短 **2.21%**，吞吐提高 **2.26%**，属于小幅收益。
- 离线将 2 或 4 个实际叶请求合批：112 次原请求输出比较中，110 次出现
  policy 或 value 差异，最大 value 差异 **0.00657003**。不能承诺合批与
  现有训练路径结果等价。
- 这不证明合批会损害学习，但没有满足“不影响训练结果”的验收要求。
  原批集中执行只有两组吞吐对照，收益尚不足以优先承担生产服务生命周期
  与维护复杂度，因此本轮不新增训练开关、不自动启用。

## 实现约束

- 每个 CPU worker 同时只有一个同步请求；它提交当前搜索原有完整批次，
  等结果返回后才继续搜索，不新增异步叶选择或未完成模拟。
- 服务端持有一个冻结的 eval 模型，逐请求执行原批大小和行顺序；
  不拼批、不补齐、不拆批、不缓存、不合并树统计。
- 每个 worker 独占固定 float32 共享输入、policy 和 value 缓冲区。
  队列只传请求头和确认信息；收到结果后先复制为独立数组，再复用缓冲区。
- 请求校验 slot、单调序号、批大小、根/叶角色、模型版本；响应核对原请求。
  policy 保留 float32，叶 policy 为只读 CPU 数组，value 回传 Python float，
  根 policy 仍为 CPU Torch tensor。
- 队列有容量限制，不等待凑批；当前单请求规则使各 worker 不会连续抢占
  多个排队位置。请求超时或响应错位会使客户端失效，并中止服务；没有
  随机值、零值、缓存值或静默回退。
- 服务端异常通过停止事件与父进程存活检查传播。实验异常只终止自己的
  worker pool 和服务进程，不终止无关 Python 进程。正常关闭先完成 worker，
  再确认服务端全部请求的次数和输入数。

代码：`tools/central_inference.py`、`tools/benchmark_central_inference.py`。
这里只支持本项目当前编码器生成的 float32 输入和原有模型架构；不宣称
任意精度、非默认后端或不同 PyTorch/CUDA 版本上的通用逐位等价。

## 一致性实验

原始结果：
central_exact/results.json（本地实验产物，未随源码分发：`data/pilots/central_exact_20261006_211736/results.json`）。

使用 iteration 16 权重，RTX 4060 Laptop，PyTorch 2.6.0+cu118；
规则/合法着 Cython、节点 Python，800/3200 次模拟，强局间隔 8，
叶批上限 64，批内去重开启，完整机会支持和 lazy chance allocation 开启。
PCR 关闭；matmul TF32 关闭、cuDNN TF32 开启；不切换精度设置。

16 局配对（14 普通、2 强），8 worker，种子 20265000 至 20265015，
两组各 8 局，按 local→central、central→local 两种顺序执行。
两条路径都记录原编码器生成的每个实际输入，以及原评估返回的每个
policy/value；流式摘要包含根/叶标记、批大小和原行顺序。

结果：**16/16 完全一致**，覆盖 **953,990 条网络输入、17,290 次评估调用、
882 条训练样本**。逐请求输入和输出摘要、训练样本所有字段摘要、RNG、
终局结果、着数、叶总量和去重数量均一致。集中路径的搜索 worker
全部确认没有初始化 CUDA。

每组单独初始化并预热模型；预热不使用游戏 RNG，不计入自博弈计时。
跟踪实验包含额外输入/输出哈希开销，不能作为吞吐测量。

## 吞吐与合批

吞吐实验单独关闭逐输入/输出哈希，并仍检查完整游戏样本和 RNG。
合批实验是独立离线对照，合批结果不会返回任何搜索或生成训练样本。

### 原批集中推理吞吐

原始结果：
central_timing/results.json（本地实验产物，未随源码分发：`data/pilots/central_timing_20261006_212712/results.json`）。

64 局配对（56 普通、8 强），种子 20265000 至 20265063，8 worker，
两组各 32 局；其余条件同上。每组单独创建并预热进程，启动与自博弈计时
分开记录。第一组 local→central，第二组 central→local。

| 分组 | 每 worker GPU 模型（秒） | 集中、不合批（秒） | 耗时缩短 |
| --- | ---: | ---: | ---: |
| 0 | 195.490 | 191.118 | 2.24% |
| 1 | 207.294 | 202.753 | 2.19% |
| 合计 | 402.785 | 393.872 | **2.21%** |

合计吞吐提高 2.26%。64/64 局样本、RNG、结果、着数和评估计数一致，
覆盖 **3,397 条样本、3,470,483 条网络输入、63,129 次评估**。
前 16 个种子与位级实验重叠，不能当作额外 16 个独立游戏种子。

原路径两次启动合计 28.762 秒，集中路径为 10.836 秒（每次约少 9 秒）。
正常训练每轮只初始化一次 pool；这里每组只有 32 局，不能把启动优势
按本实验比例外推为每轮 1024 局的提速。

| 编码至评估返回的调用延迟 | 原路径 | 集中路径 |
| --- | ---: | ---: |
| 平均 | 18.798 ms | 17.678 ms |
| P50 | 17.639 ms | 18.027 ms |
| P95 | 34.296 ms | 26.622 ms |

延迟包含编码、H2D、网络、softmax、CPU 回传，集中路径还包括通信和
共享内存复制；不是纯 GPU 内核时间。P50 没有改善，不能只报告 P95 的收益。

服务端评估累计 308.513 秒；各 worker 排队时间累计 512.642 秒，输入复制
累计 92.090 秒，结果复制累计 4.713 秒。各 worker 累计时间有并发重叠、
调度等待，不能直接相加解释进程池总耗时。记录说明通信与排队确实有成本，
不是把 8 个模型改成 1 个就能得到数倍加速。

只有两组配对，不报告可靠的总体置信区间；32 局分组仍包含强局长尾。
未测 1024 局稳态吞吐、不同 worker 数、峰值显存或长期故障率。

### 离线合批数值门槛

原始结果：
central_merge/results.json（本地实验产物，未随源码分发：`data/pilots/central_merge_20261006_214230/results.json`）。

先用原路径自博弈选取两条真实轨迹的早、中、晚期局面，补充捕获偏置
轨迹及受控残局，共 14 个局面；对各局面原预算 800 的搜索收集前 4 个
实际编码后的叶批，搜索始终使用原评估，不使用合批结果。

随后交错不同来源的请求，分别以 2 或 4 个请求为一组，离线比较
原样各自前向与拼接前向后按原顺序拆分的输出。不填充、压缩或去重，
不更改权重、eval 模式和 TF32。原批大小为 1 至 64，合批为 7 至 255；
这是本次实际覆盖范围，不宣称覆盖所有固定批大小。

| 合并请求数 | 原请求比较次数 | policy 或 value 不一致 | 最大 policy 分量差异 | 最大 value 差异 |
| ---: | ---: | ---: | ---: | ---: |
| 2 | 56 | 54 | 0.000858717 | 0.00560568 |
| 4 | 56 | 56 | 0.00188923 | 0.00657003 |

总计 42 次合批对照、112 次原请求比较，覆盖 6048 个输入行比较。
其中 policy 不一致 110 次、value 不一致 109 次；这不是按输入行计算的
不一致率。该实验只检验数值差异，没有测合批提速或对学习曲线的影响。

批形状相关 GPU 数值行为可能参与差异，但本轮没有实验定位具体内核
或 TF32 因果。开启确定性计算也不能直接推导不同批形状的逐位一致；
参见 [PyTorch 2.6 数值精度说明](https://docs.pytorch.org/docs/2.6/notes/numerical_accuracy.html)。

## 复现

先设置后端，再为每次实验创建新的输出目录。工具拒绝覆盖已有结果。

```powershell
$env:JIEQI_RULES_BACKEND='cython'
$env:JIEQI_SEARCH_BACKEND='python'
$env:JIEQI_LEGAL_BACKEND='cython'
$outputDir = Join-Path 'data/pilots' ('central_exact_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
New-Item -ItemType Directory -Path $outputDir | Out-Null
python tools/benchmark_central_inference.py --games 8 --rounds 2 --workers 8 --trace --output (Join-Path $outputDir 'results.json')
```

在另一个新的目录，吞吐测试使用：

```powershell
python tools/benchmark_central_inference.py --games 32 --rounds 2 --workers 8 --output (Join-Path $outputDir 'results.json')
```

离线合批工具同样要求新的输出路径：

```powershell
python tools/probe_merged_inference.py --output (Join-Path $outputDir 'results.json')
```

默认读取 `data/train_rules5_20261004`；可通过 `--run-dir` 显式指定别的 run。
实际模型、配置、后端身份与源码哈希写入结果，不复用已有评估输出。

不变、启动失败、服务死亡的有界等待、补丁异常恢复、旧响应/模型/序号
拒绝、超容量拒绝，以及离线合批按原请求拆分和数值差异检测。

定向测试：**12 passed，19.10 秒**，使用规则/合法着 Cython、节点 Python。
全量回归：`python -m pytest -q`，**458 passed，134.08 秒**。

三次实验各保护 17 项文件，实验结束和全量测试后再次检查：**51/51 次哈希
比较一致，覆盖 18 个不同文件**，包含权重、训练状态、生产日志、最新
replay、核心源码、实际加载的规则/合法着二进制及测量源码。

本轮没有测试实际训练进程的长期生命周期、强制 GPU 驱动挂起、长期学习
曲线或其他模型版本。只证明当前原型、当前模型和测试条件下的观察结果，
不能用有限样本证明合批不会增加训练所需数据，也不把 GPU 副本数减少
直接当作峰值显存的测量结果。

原型位于私有实验分支（未分发）；回到实验前代码快照不会回退训练权重或删除 `data/pilots`
实验结果；本轮本来也没有更改生产训练数据。
