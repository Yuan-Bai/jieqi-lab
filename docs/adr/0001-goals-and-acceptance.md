# ADR-0001：项目目标、验收标准与阶段划分

> 2026-10-22更新：下文RIS阈值及停训意向为历史阶段记录。当前强度以冻结历史池与Pika挑战分别评估，RIS不再单独作为当前棋力验收依据，见[ADR-0021](0021-opponent-pool-and-selection.md)。

- 状态：已接受
- 日期：2026-09-11
- 相关：需求访谈 Q1 / Q4

## 背景

本项目是一个揭棋 AI 实验工程。算力为本机（RTX 4060 Laptop 8GB，自博弈旧吞吐约 750–1150 局/天），无法在合理时间内追平训练规模达数千万局的成熟引擎；同时揭棋（对称隐藏信息）在公开资料中缺少可直接对照的开源 AlphaZero 实现（截至 2026-09 的检索，不代表此前不存在），值得作为方法论学习载体。

## 决策

1. **主线目标**：交付实用对弈工具（可玩 GUI + 可复现训练/评估流水线），方法论学习为辅；"冲击强引擎"作为条件性远期目标。
2. **Stage 1 验收**：
   - 规则修复与天天象棋基准对齐，差异文档化（ADR-0002~0004）；
   - 吞吐 ≥ 10×（≥1 万局/天）并有基准日志（S1.5 达成约 23× 单进程、3–4× 旧生产配置）；
   - 配对评估协议可用（`tools/eval.py`，Wilson CI + JSONL）；
   - GUI 人类视角零信息泄漏；
   - 全部测试通过。
3. **最终强度验收线**：对 RIS-800 配对评估 ≥65%（≥200 局）。
4. **后续阶段条件启动**：搜索改造（政策 target pruning 已随 S1.4 完成；批量叶评估已随 S1.5 完成；机会节点/Gumbel 待 Gate）与蒸馏放大，取决于 Gate 学习信号。

## 后果

- 短期优化重点是规则正确性与数据吞吐，而非网络规模。
- 所有搜索/目标改造必须可开关并逐项 A/B，失败可回退。

## 补充（2026-09-20）

- v4 chance-aware 主线（`docs/progress.md` §S1.25）训练内 100 局@800 评估已达 **0.725** vs RIS-800（正式验收尚未做）。用户意向：再训 40 轮后按 ADR-0007 做 200 局正式验收；**≥75% 视为项目强度目标达成并停训**（本 ADR 的验收线 ≥65% 不变）。
- 达成后：归档发布模型与验收报告；主线目标（可玩工具）进入产品化（GUI 试玩/打包）；2B 蒸馏、搜索改造等作为可选后续阶段按需启动。
- 停训判据：迭代总数 2000 为上限而非硬目标；每约 200 轮评估增量连续两次 <2pp 视为平台期。
