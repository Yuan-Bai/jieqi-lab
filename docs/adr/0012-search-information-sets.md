# ADR-0012：根一致粒子中的行动者观测与共享决策节点

- 状态：已实施并验证（2026-10-01）
- 相关：审查报告 `docs/reviews/2026-09-30-algorithm-assessment.md` B/C；Issue 0003/0007
- 实现：`ismcts.py::BeliefModel.for_simulation`、`information_set_key`、`ris_ismcts`；`azero.py::NeuralMCTS.search`

> 后续更新：本 ADR 的 71 通道兼容说明是第二批快照。第三批已通过 ADR-0013 补全公开规则历史，当前为 238 通道、DATA_VERSION=3，兼容 v2 数据和旧模型。私有历史与策略条件后验的局限仍保留。

## 问题

旧显式机会树按捕获类型分支后，每个结果持有独立的被吃方决策节点。被吃方不知道类型，因而不能用它选择策略。关闭枚举则混合了未来吃方确实知道的私有结果。与此同时，叶网络读根信念，却按照叶行动方训练语义输出策略和价值，两者不一致。

单纯改回真实 `belief.info_state(state, state.side)` 会读取根不可见的真实对手秘密，重现 Issue 0003。把对手的知识抹成根方知识也不正确：对手知道它先前吃过什么，只是根方不知道。

## 决策

### 公共账本与模拟知识

`BeliefModel.public_pool_counts` 是独立的公共计数账本：初始池计数只扣公开移动揭示，不扣私有捕获类型。`info_state` 将其复制进 `InformationState.public_pool_known`。克隆、实际对局和模拟观测均维护这份账本。

搜索仅读取真实 belief 的根观察者一次。每条模拟按这份根信息确定化一次，随后 `for_simulation(root_info, root_player, world)` 重建双方观测：

| 根为红方时的字段 | 红方模拟观测 | 黑方模拟观测 |
|---|---|---|
| 红池类型上界 | 根已有计数；保留自己的未知被吃 | 本粒子红池；黑知道它先前捕获了哪些类型 |
| 黑池类型上界 | 根已有计数，包含红的私有捕获知识 | 公共账本；黑不知道自己被吃了哪些类型 |
| 双方池总数 | 根已知的公开总数 | 同一公开总数 |

以后移动暗子的公开类型进入双方观测；捕获暗子的类型只扣吃方类型计数，被吃方只扣总数。不再使用旧的“复制根 observer 两遍”替代对手知识，也不调用真实对手 observer。

### 环境结果与决策统计分开

显式机会树继续表示环境的移动/捕获随机结果，每条模拟按当前世界池计数采样。明子吃暗子现在也有机会规格：移动结果为 `0`、概率 1，捕获类型单独随机；没有虚构公开翻子。

结果边经过实际 `apply_move` 和观测更新后，连接到行动者决策节点。一次搜索内用共享表查找决策键：

- 从根开始的公开走法与移动揭示序列；
- 行动者从根开始亲自观察的捕获事件序列；
- 行动者的池计数、总数、未知被吃量，以及公开棋盘/规则字段。

键中不含世界真池或另一方私有捕获事件。当前网络仍使用原来的行动者计数输入；决策键比网络编码保留更多搜索内观测历史，网络前向可以去重，但不能因此把不同私有观测序列的决策统计合并。

例如红吃黑暗车/暗马、公开移动类型相同：两个环境结果均连接同一黑方决策节点。黑随后吃红暗车/暗马：红不会因此区分自己被吃类型；红仍会区分它之前亲自吃到的黑子类型。若黑已有不同的私有知识，其模拟策略可以不同，红根统计对这些可能性汇总。

NeuralMCTS 的先验与叶价值来自合成行动者观测，与训练输入的观察者约定一致。ISMCTS 同样按行动者信息键共享决策，保留根一致采样和现有 rollout/子力估计。

### 回传

共享决策节点有多个环境入边，形成决策图。NeuralMCTS 沿实际模拟 path 回传；ISMCTS 改为相同方式，`Node.parent` 仅保留首次连接作结构记录，不能用于回传。

动作边、机会结果和后继决策都按走后行动方记账。额外结果/决策层不换手，只有行动方改变才翻转价值。NeuralMCTS 每条 path 的临时访问与虚拟损失均按实际经过的节点添加和回收。

## 验证

`test_search_information_sets.py` 新增 8 个测试，覆盖：

- 根方不知自身被吃类型，对手知道粒子中的类型；不同粒子保持相同根观测；
- 改变真实隐藏捕获结果/真实对手私有观测，NeuralMCTS 与 ISMCTS 的根结果不变；
- 模拟对手的网络先验随它自身的采样知识变化；
- 暗吃暗/明吃暗、机会 on/off：被吃方共享决策，吃方保留自己的私有分歧；
- 共享图沿实际 path 回传，访问数汇总及虚拟损失回收正确；
- 搜索内私有观测顺序不同不能合并；明吃暗导航服从当前世界池。

第一批 `test_search_reveals.py` 保留逐着法合法性核验和双首展顺序，改为检查结果边连接的决策节点：翻炮 **6**、翻兵 **44**，没有丢失原回归约束。旧 R3 测试现在区分真实 belief 与合成 belief，继续禁止读取真实对手秘密，而不是禁止模拟对手拥有知识。

## 兼容性与范围

网络仍为 71 通道，`DATA_VERSION=2`、`RULESET_VERSION=3` 均未改变。旧模型和数据可加载，已有模型实际加载通过；本次未训练或覆盖权重/历史数据。未来生成的搜索目标及 RIS 对手语义已改变，不应与旧结果直接当作相同口径比较。旧样本仍含旧搜索目标，续训时会逐渐被新数据替换。

这是一项信息边界与节点共享修复，仍不是完整的不完美信息求解器：

- 根前的私有捕获沿用组成计数抽象，尚未重建完整的私有事件顺序；搜索内则保留逐事件观测。
- 决策 Q 仍按根采样分布回传，共享行动者信息键不保证这些样本正好等于行动者的策略条件后验。没有新增从对手走法推断隐藏类型的后验更新，也没有公共信念子博弈求解或 CFR/均衡收敛保证。
- 公开规则历史缺项已由 ADR-0013 修复；固定支持偏差已由 ADR-0014 修复，k 改为初始预建上限，默认仍 k=0。策略相关历史仍有限。
- 更多信息集节点和观测键会增加 CPU/内存开销；尚未量化棋力或等时间收益。

信息集搜索的基本依据见 [Cowling、Powley、Whitehouse 的原论文](https://eprints.whiterose.ac.uk/id/eprint/75048/)。本实现是基于现有 PUCT/UCT 的工程扩展，没有声称复现论文全部算法。
