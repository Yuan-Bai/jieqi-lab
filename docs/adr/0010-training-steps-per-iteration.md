# ADR-0010：每轮训练步数恢复固定值（train_steps=1000）

- 状态：已接受
- 日期：2026-09-13
- 相关：ADR-0005（训练卫生）、ADR-0008（ruleset_version）；Gate 失败复盘

## 背景

Gate（v3 规则、320 轮 × 64 局）验收未通过：

- 200 局 @800 sims 对 RIS-800：58W/1D/141L，score 0.2925（Wilson CI [0.234, 0.359]）；对随机基线 0.9525。
- 训练内快评（16 局@400 vs RIS-200）320 轮无上升趋势；最终 policy loss 3.03（目标熵约 2.3 nats）。
- 价值头退化：held-out `corr≈0.16`、`pred std≈0.20`（近似常数 0）。
- 自博弈和棋率由 iter0 的 8/64 涨至 iter100-300 的 30-39/64。

根因定位到 S1.4 的 `compute_train_steps()`：它按“新增样本 1 epoch”折算步数（`added/batch`）。
在本项目数据率（64 局/轮 ≈ 9k 样本/轮）与 1M buffer 下每轮只有 13-25 步（平均 16）：

- 每轮抽样量 15×512 ≈ 7.7k，约等于新增样本量；每 batch 中新数据仅占 0.77%，
  单个样本整个生命周期（约 110 轮）平均仅被训练约 1 次——等价于不训练。
- 对照 AlphaZero 每轮 1000 步 × 2048 batch；本项目研究笔记（`docs/research_jieqi_azero.md`）
  原本建议“按新增样本量设 `train_steps`，或改为固定 epoch 数（1–4 epoch/迭代）”
  （当时 buffer 35k，1 epoch ≈ 68 步），实现却变成对 buffer 每轮约 0.008 epoch，过度修正约 3 个数量级。
- 旧管线日志（`data/legacy_20260911/logs/`，1000-1200 步/轮、64 局/轮）显示 loss 单调下降
  （3.96→1.98，22 轮）；但旧管线含已知规则/搜索缺陷（ADR-0009）且从未通过评估验证，
  仅作“该训练量级在本项目可跑通”的旁证，不作为正确性依据。

## 决策

1. `compute_train_steps(steps, batch_size, buffer_size)` 改为**固定步数制**：
   每轮对 replay buffer 均匀采样训练 `steps` 步（AlphaZero 风格）。
   `train_steps` 由“上限”改为此步数，默认 **1000**（1M buffer 下约 0.5 epoch/轮，
   样本在生命周期内复用数十次）。
2. 删除 `train_epochs` 与 `--train-epochs`：其“新增样本 epoch”语义与固定步数制冲突。
3. 自博弈汇总日志新增每轮“新增样本数”（`新增=%d`），便于观察数据率与训练量比。
4. 先短跑 pilot（在现有 v3 模型与数据上续训约 32 轮）观察 loss / 和棋率 / 快评曲线，
   再决定是否跑完整 Gate。pilot 通过判据：policy loss 明显下降、value loss 明显下降、
   和棋率回落、快评不劣化。

## 后果

- 每轮训练时间由约 2.5s 增至约 150s（实测 0.148s/step、1000 步）；320 轮 Gate 总时长
  预计由约 27h 增至约 37h（自博弈约 250s/轮 + 训练约 150s/轮）。
- 不复用旧管线数据/模型（v0/v2 已归档）。当前 320 轮 v3 数据与 `latest.pt` 为弱模型产物，
  但规则正确、meta 版本匹配，默认续训复用；如需“干净复现”，可归档后从 iter 0 重跑。
- 若 pilot 显示 loss 正常下降但强度不改善，则瓶颈不在训练量，需转向搜索目标质量
  （RIS 确定化、暗子机会节点等 ADR-0005 第 5 条路线）。
