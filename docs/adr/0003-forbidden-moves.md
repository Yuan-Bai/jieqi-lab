# ADR-0003：长将/长捉的"禁着"语义

- 状态：已接受
- 日期：2026-09-11
- 相关：需求访谈 Q2 / Q10；天天象棋官方规则

## 背景

天天象棋规则：同一方用同一枚棋子连续长将或长捉超过 6 回合后，不得继续该行为（禁着）；若没有任何替代着法，则判负。旧实现为"连将计数 >3 即判负"，既阈值不符，也缺少长捉概念，且在无替代着法时应判负而非"和/其他结果"。

## 决策

1. **定义**：
   - 长将：同一方的**同一枚棋子**连续将军；
   - 长捉：同一方的**同一枚棋子**连续攻击**同一枚敌方非将、非兵棋子**（兵排除在外，符合中国象棋"捉兵不算长捉"惯例）。
2. **阈限**：连续 6 回合（12 ply）。
3. **禁着**：达到阈限后，`legal_moves()` 剔除"仍将军/仍追同一目标"的着法；吃子、换目标、放弃追踪均放行。
4. **无替代判负**：若走方全部着法均被禁，则该方判负（结果 reason=`long_check` / `long_chase`）。
5. **实现**：`consecutive_checks[side]` 与 `chase_streak[side]`（配套 `chase_target` 目标格与 `chase_target_code` 目标棋子码）在 `apply_move` 中维护；换目标/目标被吃即重置。“同一枚棋子”由 `check_anchor` / `chase_anchor`（该棋子最近一次落点）保证：只有从锚点格继续走子并保持将军/追同一目标才累加计数，换子接手即重置（v3 修正，见 ADR-0009）。`game_outcome` 用 `_move_scan()` 区分"被禁着法"与"无合法着法"。
6. **回退**：`RulesConfig.forbidden_moves=False` 恢复旧式即时判负（legacy 预设，仅测试用）。

## 后果

- 搜索与自博弈看到的是禁着过滤后的合法着法集合，长将/长捉不会在搜索树中被重复利用。
- 可配置参数：`long_check_rounds`、`long_chase_rounds`。
