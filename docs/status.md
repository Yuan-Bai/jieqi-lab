## 当前工作顺序

1. 生产仍用当前信息集搜索与已验收的精确加速，保留完整续训检查点；不自动开始新轮或修改配置。
2. 下次续训在核对过的原参数上增加冻结历史池，每次三个对手各100局；Pika低频独立挑战。源码已接入，当前生产检查点尚未运行这一新策略。
3. 正式晋升需预先固定新留出种子、局数与比较政策；当前340局不支持直接更换冠军。不要以RIS最高分、loss或单次探索区间判断整体进步。
4. 后续性能实验先独立测量，再做精确性验收；不自动开启网络评估缓存、跨 worker 合批、AMP/PCR 或更改模拟预算。不可变机会概率表复用不是网络缓存。
5. 图搜索按独立门槛推进：先复现完整新增换位，再固定模型配对棋力，最后多种子训练收敛；首测未过，不替换生产搜索。
6. FP16推理独立复验未通过完整局吞吐筛选，降优先级；未来重启须先分离strong尾部与机器状态，不能跳过吞吐门槛。训练更新/续训精度不变。
7. 完整机会表复用、中间层信息集键直接生成分别经192局精确配对验收；全部保留加速已完成1024局联合基线。降低零散微优化优先级，暂不主动推进节点初始化、表容量、键/字段等约1%散点优化；优先稳定训练与固定诊断，不自动启动续训。
8. 原生隔离CUDA/CPU覆盖、无跟踪稳定性、blocking等待及当前Python函数栈采样已完成，不再管理员采样。等待候选根吞吐+3.06%，但完整局-2.37%，不接生产。直接编码、PUCT选择、历史身份复用均精确，局部省时24.27%/15.05%/69.03%，根吞吐+0.411%/-0.401%/-0.967%，均未过筛选并停止，不做整局/接入。停止本轮散点CPU原型扩展，不将局部或条件GIL样本当生产收益。优先稳定训练/固定诊断，不自动续训；未来若重启CPU大幅提速，先为明确对象/状态复制成本另订结构实验和完整局预算，验收信息隔离/历史所有权/回传/网络/RNG，不在当前续训内重构。旧节点初始化更慢、已编译合法着调用者排名高，不支持扩大编译或承诺10%收益。旧慢参照后台功耗解释仍是假设；短局在途比例40%--44%不是1024局高并发结论。若重启等待研究先另订高并发/热态/后台记录协议，不放宽门槛或改全局调度flags。

当前已使用1250更新步；本次评估接入不调整学习率、更新步数、worker、叶 batch 或 replay 容量。
节点初始化编译更慢；合法着已开时节点扩展收益不稳定。集中 GPU 不合批只有小幅收益，
合批和跨批次缓存未通过严格数值门槛，均不接生产。具体证据在 performance 索引中。
