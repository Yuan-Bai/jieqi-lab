## 修复记录（2026-09-14）

`NeuralMCTS.search` 原为 RIS 语义：每次模拟根确定化一次，之后每个节点按该节点
行动方 `determinize` 重抽（`azero.py` 旧 963 行），叶评估用行动方 `InformationState`
（`sim_belief.info_state(sim_state, sim_state.side)`）。私有观测经 `ismcts.py:217-229`
只进吃方，因此叶输入在不同行动方视角下可以读到根玩家不可知的信息。

修复内容：

1. 每条模拟只在根确定化一次（根玩家视角），整条模拟复用同一世界——删除每节点重抽。
2. 叶评估与机会规格必须使用**根玩家的公共视图**：搜索开始时把根观察者的
   两个观察者槽复制成同一个 `BeliefModel`（`root_belief`），每次模拟克隆它并随
   走子 `observe_move` 更新；`leaf_info` 与 `_chance_specs` 均取该视图。
   仅"单次确定化"是不够的——`belief.clone()` 仍会保留对手私有行，必须显式构造。
3. 不改变网络"行动方视角"约定（value 标签与叶评估语义不变），无需重训即可
   消除通道；未来若要改用根 observer 视角评估，需按方案 2 重训。
4. `ismcts.py::ris_ismcts`（纯搜索基线/评估对手）同步切换为根视角单次确定化：
   删除每节点 `info_state(state, state.side).determinize` 与随之而来的
   `observe_move` 记账；每条迭代只在 `info_state(root_state, root_player)` 确定化一次。
   该路径没有"叶值读私信"的神经网络通道，原 RIS 重抽只会把对手私信带进
   模拟世界分布；统一后两条搜索语义一致。函数名与 `ISMCTSAgent` 保留（兼容）。

验证（详见"修复验证"小节）：修复后仅改对手私有信念行，搜索的全部叶评估输入、
根 policy、根价值完全一致；把 `search`/`ris_ismcts` 还原为旧语义后，对应测试立即失败。

## 原始疑点与修正

初判怀疑"共享树跨行动方混合"：所有模拟共用一棵树，而每条模拟按该节点行动方重确定化
（RIS），对手视角统计经 `_backup` 回流到共享节点。**机制分析修正**：

- 本实现每次 `search` 新建 root（`azero.py:922`），不存在跨回合树复用；根节点层
  只由根行动方的确定化模拟更新。
- 真正通道是**叶节点评估**：叶值/展开先验用"叶行动方"的 `InformationState`
  （`azero.py:980/931`），而 `pool_known/unknown_removals` 含**行动方私有观测**
  （吃暗子揭示只入吃方，`ismcts.py:217-229`）。叶值 = E[胜负 | 叶行动方私信]，
  经 `_backup` 翻视角回传后，根 Q 不再是根信息集可测的函数。
- 对手节点重抽世界是第二通道，但实测近似休眠（见下）。

## 实验证据（agent C，脚本见临时目录 `ris_leak_*.py`）

构造：随机推演至 10 ply，BLACK 私下捕获 2 枚红暗车（强制揭示车）；RED 行
`rook=2,unknown=2`，BLACK 行 `rook=0`。A=真实 belief；B=仅把 BLACK 对红池的行
替换为 RED 行。断言两条件下根 `InformationState` 全字段相同。

| 条件 | 根价值 V（A vs B） | 落子变化 |
|---|---|---|
| stub（含池 EV）200 种子@400 | +0.4485 vs +0.5145，diff −0.0659±0.0003 | argmax-Q 193/200 |

| 真实 latest.pt 100 局@400（1 车） | +0.3156 vs +0.1979，diff +0.1176 | 0/100 |

## 影响

- **(a) 选招**：真实可达。均势/多候选局面下泄露使根排序随机化并翻盘（2 车局面
  84/120）；有明确最佳着时不动（0/100），但根价值估计被大幅偏置。
- **(b) 训练策略目标**：policy target = search visits，依赖对手私信而网络输入不含
  该信息 → 不可约目标偏差/噪声。value target 是真实胜负，不直接污染，但自博弈
  轨迹由带泄露策略生成。
- **(c) 评估口径**：`_play_eval_game` 中 NN 与 RIS 基线**双方都按行动方重确定化**
  （RIS 仅世界通道，NN 另有叶值通道）→ "泄露 vs 泄露"，ADR-0007 的 ≥65% 只证
  相对进步，不能据此主张对人类强度；GUI 人机 AZ 对手同理。
- **自博弈训练无被利用方**（双方同一策略），危害主要是统计偏差与目标噪声；
  对 leak-free 对手/人类才构成信息优势。

## 解决思路（2026-09-14 更新：已按 3+2' 的轻量组合实施）

1. **文档化（推荐先做）**：ADR-0005/0007 补记 RIS 私信泄露与评估口径限制；
   `docs/research_jieqi_azero.md` 已引 Goodman 对 RIS"假确定化污染统计"的说明。
2. **叶值/先验改用根观察者**（部分修复）：`azero.py:980/931` 用 `root_state.side`
   编码。关掉实测最大通道；但网络"行动方视角"约定需改并**重训**，可能掉棋力。
3. **根视角 sole determinization（SO-ISMCTS）**：`azero.py:963` 固定根 observer；
   去掉世界通道，但需与方案 2 配合，且模拟对手会"看见采样世界"（另一类 fusion）。
   小改，可按 ADR-0005 以开关形式做 A/B。
4. **per-observer 统计**：单次搜索模拟同根玩家，此方案**不解决**本泄露，不建议。
5. 组合建议：1 立即做；2 或 3 做成开关，按 ADR-0005 跑 200 局配对 A/B 后由 Gate 定夺。

**实际实施（已修复）**：方案 3 的"根视角单次确定化" + 方案 2 的轻量变体
（不换网络视角，只把叶评估/机会规格的信息源换成根公共视图）。这是唯一不需要
重训、同时封住叶值通道的组合；模拟对手"忘了自己的私有观测"按用户裁定即正确语义。
方案 2 的完整版（把网络输入换成根视角编码）留作未来选项。

## 分歧记要（训练 agent 反驳与本文件裁定）

训练 agent 主张：R3 不构成泄露——"引擎按对手知识模型评估对手节点"是 RIS/PIMC
设计；实验条件 B（把对手私信换成错误模型）是人为构造；训练上属目标噪声，
"塔性质（tower property）保证无不可约偏差"；建议只写口径注记 + 可选 A/B。

裁定：**塔性质论证不成立，机制仍是根信息集可测性违背；但其"无免费可 exploit、
只宜文档 + A/B"的操作建议基本正确。** 理由：

- 塔性质 `E[E[X|G]|F] = E[X|F]` 要求 `F ⊆ G`（F 比 G 粗）。但根玩家的信息集
  F_root 与叶行动方（对手）信息集 F_leaf 是**交叉而非嵌套**：根知道自己的私信
  （如"我方丢了 2 枚暗子但不知类型"），对手知道它的私信（"吃到的是 2 车"），
  二者互不包含。故 `E[X | F_leaf]` 不是任何 F_root-可测量的条件期望，
  回传到根 Q 后**没有理由**等于根视角期望；实验中的价值漂移与落子翻转
  （84/120）正是系统性偏差，而非纯噪声。
- 更深一层：确定化取的是**对手后验** `P(根方暗池 | 对手观测)`，而根决策应使用
  **根自己的后验** `P(世界 | 根观测)`。根不知道自己丢了什么类型（unknown=2），
  对手知道（rook=0），二者的世界分布不同。
- 让步项：自博弈双方同算法、同偏差，无"被利用方"，不构成对人类/leak-free 对手
  免费可 exploit 的优势；实验位置（2 车私信差）是效应上限；普通对局大部分
  私信对称，影响应显著更小。因此"文档化 + 可选 A/B"的优先级判断合理。
- 但注意：条件 B 并非"从未可能出现的信念"——真实对局中双方信念本来就分叉
  （被吃方不知道类型、吃方知道），B 只是把分叉方向换成了另一种可达形态，
  用于隔离"叶行动方私信"通道本身。

## 不确定性

- board-only stub 表明世界重抽通道在当前深度近似休眠，但未证否。
- 真实网络下 A/B 泄露方向与 stub 相反（净相关结构不同），勿用单一局面外推棋力。
- 若 root-only + 重训后强度无显著差异，可降级为"只记文档"。

## 修复验证（2026-09-14）

回归测试 1：`test_azero.py::TestSearchInformationSafety::test_opponent_private_belief_does_not_leak_into_search`（神经网络搜索）。

- 构造：随机对局快照到"黑真实吃掉红暗子"的局面（黑由此获得类型私信）；
  A = 黑保留真实私信；B = 把黑对红池的该类型计数/未知计数退化成"只知少一子"。
  两条件下红方（根）`InformationState` 逐字段相同。
- 断言：叶 trace（每次叶评估携带的 side + 双方池计数）完全相同、落子相同、
  policy 逐元素相同、根价值相同；并断言叶池计数不超出根已知上界。
- 判别力：把 `NeuralMCTS.search` 源码文本还原为旧语义（每节点重抽、叶用行动方
  私信）后，同一测试在 `trace_a != trace_b` 处失败（验证脚本：`verify_test_discriminates.py`，
  临时目录）。
- 全量：`pytest tests/test_azero.py tests/test_ismcts.py tests/test_jieqi.py tests/test_eval.py` → 82 passed。

回归测试 2：`test_ismcts.py::TestIsmctsRollout::test_ris_ismcts_determinizes_only_root_observer`（纯搜索）。

- 以 spy 记录搜索期间 `BeliefModel.info_state` 的 observer：修复后每条迭代恰好 1 次、
  且只出现根玩家；旧语义下出现对手 observer 且调用次数为迭代数的百倍量级
  （实测 7 迭代：修复 7 次 vs 旧版约 1000+ 次；300 迭代实测 300 vs 9758）。
- 判别力：源码文本还原为旧语义后，同一测试在 `sorted(set(observers)) == [root_player]` 处失败
  （验证脚本：`verify_ris_test_discriminates.py`，临时目录）。

修复过程中的两个关键教训：

1. 只做"单次确定化"（第一版修复）仍会被测试抓住——`belief.clone()` 保留对手
   私有行，叶评估读行动方槽位时依旧带入私信；必须显式构造根公共视图。
2. 桩网络必须确定性（测试用固定 `stub_forward`），否则两次 `PolicyValueNet()`
   初始化不同会掩盖叶输入差异。

## 遗留

- 评估口径：`_play_eval_game` 中 NN 与 RIS 基线现在都用根视角单次确定化，
  仍属"同一偏差下的相对比较"；ADR-0007 的 ≥65% 记录的是修复前基线，
  后续正式评估建议按 ADR-0005 重跑一次以刷新基线数值。
- 强度影响未做 A/B：本次修复改变了两条搜索的世界分布（对手不再"预知"私有
  观测），可能影响棋力；按 ADR-0005 的 200 局配对评估可给出量化结论。
